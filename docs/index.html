Industrial Mind & Code

Where should AI sit inside industrial systems?

Industrial Mind & Code is an independent applied research program testing LLM agents inside industrial engineering decision environments — supply chains, maintenance systems, production planning, manufacturing workflows, and product-lifecycle systems.

The early result is not “AI beats everything.” It is more interesting: LLM agents often fail when placed directly in control of operational decisions, but become useful when constrained inside the right architecture.

The central research question: where should probabilistic intelligence sit inside deterministic industrial systems?

Researcher Siddharth Srinivasan

AI agents do not fail because they are stupid. They fail because we put them in the wrong part of the system.

Emerging Thesis

Emerging Thesis

Industrial AI agents should not be evaluated as generic chatbots or benchmark performers. They should be evaluated as decision-making components inside constrained industrial systems.

Across these experiments, a pattern is emerging:

  1. Better models do not automatically produce better industrial decisions. Reasoning-tier and larger models can still amplify instability when placed in the wrong decision role.
  2. More context can make agents worse. In several supply-chain experiments, added context increased reactivity rather than improving control.
  3. Deterministic baselines are hard to beat. Simple methods like exponential smoothing often outperform LLM agents on stability, variance, and stockout performance.
  4. Architecture matters more than intelligence. Perfect labels, better prompts, and more capable models do not help if the AI is placed in the wrong part of the control loop.
  5. Hybrid systems are the promising path. LLMs look more useful when they select bounded parameters, classify states, or assist engineers — not when they directly control operational quantities.

The practical design question is therefore not whether AI should replace established industrial methods. It is where probabilistic reasoning can safely improve deterministic systems — and where it should be constrained by them.

Featured Result

Featured Result

Featured Finding

In the first supply-chain replenishment study, every heuristic baseline outperformed every LLM configuration on both order variance and stockouts. Exponential smoothing achieved chain OVAR of 0.54 with 5 stockouts; the best LLM configuration produced OVAR of 4.33 with 41 stockouts.

But the conclusion was not “LLMs are useless.”

Later experiments showed that when AI was moved away from direct order control and instead asked to select the smoothing parameter inside a deterministic control loop, every AI condition produced OVAR below 1.0. The best result marginally beat the fixed α = 0.3 baseline.

The lesson: AI performance in industrial systems depends less on model intelligence alone and more on where the model is placed in the architecture.

Sharp Findings

Sharp Findings

You cannot prompt your way out of the bullwhip effect.

Prompting helped structure behaviour, but it did not make LLM agents outperform simple deterministic replenishment rules.

More context can make an industrial agent worse.

Additional context can increase reactivity and instability if the agent is placed in the wrong control role.

Perfect labels cannot fix the wrong control architecture.

Even oracle-style classification does not help if the LLM is still controlling the wrong operational variable.

Reasoning tokens are not operational intelligence.

More deliberate model reasoning does not automatically translate into better industrial system performance.

The question is not whether to use AI, but where to place it.

The strongest results appear when AI is bounded inside a hybrid architecture rather than given direct operational control.

Methodology

How experiments are designed

01

Controlled simulation environments

Parameters are synthetic but calibrated against published literature. All scenarios are fictional. No proprietary data is used.

02

Analytical baselines

Performance is measured against deterministic methods that already exist for the problem: exponential smoothing, order-up-to policies, SPC rules. The evaluation question is whether LLM agents add value beyond established approaches.

03

Model performance across deployment surfaces

Each experiment tests models across frontier and local inference, spanning lightweight and reasoning tiers. Model tier, context treatment, and inference backend are treated as experimental factors, not background conditions.

04

Optimised architecture

Experimental results are used to identify where hybrid deployments (combining LLM agents with deterministic methods) may outperform either approach alone. The design question is not whether AI replaces the established method, but whether and where it can improve on it.

About

About Industrial Mind & Code

Industrial Mind & Code is an independent applied research lab by Siddharth Srinivasan, focused on industrial AI systems, agentic decision-making, and engineering workflows.

The work explores how LLM agents behave inside constrained industrial environments — including supply chains, maintenance systems, product lifecycle workflows, manufacturing operations, and edge deployments.

The bias is practical: compare AI agents against deterministic baselines, measure operational outcomes, and identify where hybrid architectures are more reliable than direct agentic control.
