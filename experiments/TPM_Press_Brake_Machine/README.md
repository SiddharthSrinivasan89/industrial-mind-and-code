# TPM Press Brake Machine

LLM-assisted reasoning for Total Productive Maintenance (TPM) on press brake equipment.

---

## What This Is

An experiment exploring whether LLM agents can support TPM workflows for press brake machines — interpreting maintenance logs, reasoning about failure modes, and surfacing actionable recommendations aligned with TPM pillars (autonomous maintenance, planned maintenance, focused improvement).

---

## Files

| File | Description |
|------|-------------|
| `agent.py` | Main LLM agent |
| `agent_o3.py` | o3-based reasoning variant |
| `experiments.md` | Initial experiment runs and observations |
