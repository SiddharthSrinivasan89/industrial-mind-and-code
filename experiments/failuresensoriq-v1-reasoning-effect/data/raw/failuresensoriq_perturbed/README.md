# FailureSensorIQ — perturbed split (data not republished here)

These files are perturbed variants derived from IBM Research's **FailureSensorIQ** benchmark and are
**not** included in this repository. Get the base dataset from the official source and regenerate the
perturbations, or contact me:

- Hugging Face: https://huggingface.co/datasets/ibm-research/FailureSensorIQ
- IBM GitHub: https://github.com/IBM/FailureSensorIQ
- Paper: https://arxiv.org/abs/2506.03278

Original files that live in this directory in the working copy:

- `perturbed_simple.jsonl`, `perturbed_complex.jsonl` — simple and complex perturbation sets.
- `all_10_options_all_perturbed_simple.jsonl`, `all_10_options_perturbed_complex.jsonl` — 10-option variants.
- `*_review.md` — my per-item audit notes on the perturbed items.
