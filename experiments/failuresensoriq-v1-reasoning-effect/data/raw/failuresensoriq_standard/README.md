# FailureSensorIQ — standard split (data not republished here)

These files are part of IBM Research's **FailureSensorIQ** benchmark and are **not** included in this
repository. Download them from the official source:

- Hugging Face: https://huggingface.co/datasets/ibm-research/FailureSensorIQ
- IBM GitHub: https://github.com/IBM/FailureSensorIQ
- Paper: https://arxiv.org/abs/2506.03278

Original files that live in this directory in the working copy:

- `all.jsonl` — single-true multiple-choice QA; the 2,667-question split used as the baseline here.
- `all_10_options.jsonl` — fixed 10-option variant.
- `all_multi_answers.jsonl` — multi-true variant.
- `*_review.md` — my per-item audit notes flagging benchmark keys that may be arguable.
