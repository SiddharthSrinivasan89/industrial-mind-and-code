Agentic Bullwhip Effect: Version 2a

Does an LLM trained on Indian data show better seasonal awareness in an Indian supply chain context? V2a replaces the generic OSS stack with sarvam-30b and holds everything else constant.

Date March 2026
Experiment Agentic Bullwhip Effect Version 2a
Design 2×2 Factorial · 20 runs · ~5,760 LLM calls
Status Results pending

Abstract

Version 2 found that no LLM configuration — including a 120B reasoning model — outperformed exponential smoothing on order variance or stockout count. The demand series is calibrated to Indian seasonal patterns: FY-end peaks, monsoon dips, Diwali and Navratri surges. But the models tested were trained predominantly on Western data.

Version 2a asks whether that matters. sarvam-30b (Sarvam AI) is trained for Indian language and context proficiency across 22 Indian languages, with the Indian market as an explicit training focus. Everything else — supply chain, demand series, conditions, success criterion — is identical to Version 2. Only the model changes.

Experiment setup

Design & configuration

Modelsarvam-30b Q4_K_M — Sarvam AI · MoE architecture · 2.4B active params of 30B total · 22 Indian languages
Design2×2 factorial: model tier (lightweight / reasoning) × context treatment (blind / context). Both tiers use the same model.
Replications20 per LLM condition · 1 per heuristic (deterministic, reused from V2)
Primary metricsOVAR (Order Variance Ratio) + Stockout count, always reported jointly. MPRD: |ΔOVAR| ≥ 0.5 required for a practically meaningful claim.
Supply chain3-tier serial: Tatva Motors (OEM) → Lighting Manufacturer (Ancillary) → LED Component Manufacturer
Demand series25 months (Jan 2025 to Jan 2027) · single SKU · two full Indian festive cycles
Lead time1 month deterministic at all tiers
Initial inventory43,609 units, derived as mean + 1.65σ of demand series (~95% service level)
LLM calls~5,760 total (4 conditions × 20 runs × 24 ordering periods × 3 tiers)
Heuristic baselinesExponential smoothing (α=0.30) · Naive passthrough · Order-up-to (reused from V2)
Agent designStateless, no memory between periods
Temperature1.0 all conditions (per model documentation specification)
Inferencellama-server (llama.cpp b8468), local, GB10 GPU, llama-gguf-split merged GGUF

OVAR interpretation: < 1.0 = dampening · = 1.0 = pass-through · > 1.0 = bullwhip amplification

Key findings

What I found

  1. Results pending — full run in progress. This post will be updated when the 20-run experiment completes. Preliminary smoke test data suggests the model runs without structural failures.
  2. V2 baseline for comparison. Exponential smoothing: chain OVAR 0.54, 5 stockouts. Best V2 LLM result: gpt-oss:120b at OVAR 4.52 (blind and context). Pattern score 0.20–0.23 across all conditions — no seasonal awareness detected in any V2 configuration.
  3. Hypothesis: Indian training data may produce a genuine context effect. gpt-oss:120b showed essentially zero context effect (OVAR 4.52 in both blind and context). If sarvam-30b responds positively to the seasonal tier personas, it would be the first evidence of culturally-informed ordering behaviour in this experiment series.
  4. MPRD threshold: |ΔOVAR| ≥ 0.5. A difference smaller than 0.5 OVAR points is not practically meaningful. sarvam-30b would need to achieve chain OVAR ≤ 4.02 to represent a real improvement over the best V2 local result.

Discussion

Why this version

The core question V2a addresses is whether model training data matters for this task. V2 used models trained predominantly on English-language internet text, with minimal representation of Indian market dynamics. sarvam-30b was explicitly trained for Indian language and context proficiency across 22 Indian languages, with the Indian market as a primary focus.

Two mechanisms that could produce a different result

Seasonal term recognition. The context condition provides tier personas that reference festive cycles and Indian agricultural seasons. A model trained on Indian data may link "Diwali season" or "monsoon period" to demand patterns more reliably than a general-purpose model. This would show up as a higher pattern score — the fraction of seasonal event months where the agent's rationale mentions relevant keywords and order quantities move in the correct direction.

Calibrated prior expectations. sarvam-30b may have a more accurate internal prior for Indian market demand trajectories, producing ordering decisions that are more regime-aware even in the blind condition. This would show up as lower OVAR under the blind condition, where no contextual cues are provided.

The structural constraint still applies

The argument from V2 remains: stateless agents without memory cannot self-correct. If over-ordering occurs in period t, the agent arrives at period t+1 with no record of it. No amount of cultural training addresses this constraint. The hypothesis is therefore specific — it predicts higher pattern scores and a potentially positive context effect, not a wholesale reversal of the bullwhip failure.

If sarvam-30b closes the gap, even partially, it would be the first evidence that domain-specific training affects ordering behaviour in this setting. If it does not, it strongly suggests the failure is structural rather than a knowledge gap.

Methodology note

All scenarios, companies, products, and supply chain structures are entirely fictional. The experiment is intentionally narrow: single product, fixed lead times, stateless agents, no unstructured context. Results should not be generalised to supply chain management broadly. The correct scope: does sarvam-30b, with Indian-focused training, show stronger seasonal alignment than general-purpose LLMs in a stylised single-product replenishment task with fixed lead times and no unstructured context?
